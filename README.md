# Kiyoki — Next-Gen Clean Air Technology

A modern, high-performance landing page for Kiyoki Air Purifiers built with React 19, TypeScript, Vite, and Tailwind CSS.

## 🚀 Features

- **Header & Navigation:** Responsive sleek header with Kiyoki branding, navigation links, quick search modal, and cart drawer.
- **Hero Banner:** Full-width lifestyle carousel featuring high-definition photography with smooth pagination and call-to-actions.
- **Clean Air Video Section:** Tesla-style two-column section with dynamic typography, pollutant removal metrics, and an integrated video player with auto-hiding controls.
- **Product Card Carousel:** Swipeable horizontal product carousel with smooth track scrolling and custom indicators.
- **5-Stage Filtration Technology:** Full-width dark technology showcase featuring an animated video background, 3D filter component cards, and deep atmospheric bottom gradient.
- **Meet The Green Team:** Interactive expanding accordion product cards (X8, X3, X5) with synchronized specs, room capacities, and "Shop Now" interaction.

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React Icons**

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Deploy on Vercel

This repository is optimized for one-click deployment on [Vercel](https://vercel.com).
- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`
